Discrete dynamics / median filters

Median filters
can oscillate

A binary median filter replaces each pixel by its neighborhood’s majority. Repeated updates can alternate between two images indefinitely.

For every nontrivial centered symmetric mask, we can build a periodic image that flips every pixel at each update.

Theorem 1 · the precise claim

A periodic two-cycle for each mask

Take a finite mask W = {0, ±a₁, …, ±aᵣ} ⊂ ℤᵈ, with r ≥ 1 nonzero offsets, distinct up to sign. All samples have equal weight; all pixels update at once.

FW(x) = −x   ⇒   FW²(x) = x

If every coordinate of every offset has magnitude at most M, a common spatial period satisfies 2 ≤ N ≤ (2M + 1)ᵈ − 1.

The spatial period N and the temporal period 2 are different. N need not be minimal. This proves the centered symmetric periodic case of the median-cycle question, not the full characterization in Klette’s Problem 3.

01 / Separate the offsets

Encode the offsets as integers

Use base B = 2M + 1 and encode a lattice point as ℓ(v) = v₀ + Bv₁ + B²v₂ + ⋯.

Two points in the mask’s box cannot collide: their highest differing digit outweighs all lower digits combined. Thus the absolute projected offsets are nonzero and distinct.

Call the largest one p. On a cycle of length N = 2p, its positive and negative directions reach the same antipode.

02 / Improve opposite pairs

Increase the cut by flipping opposite pairs

Require y(t + p) = −y(t). Opposite positions always have opposite signs. Flipping both signs preserves this rule. Start with p ones followed by p zeros: this satisfies the opposite-pair rule, but need not yet satisfy the majority condition.

Temporarily set the extreme pair aside. There are k = r − 1 remaining pairs. Let c(t) count their samples that disagree with the center.

Count the cut edges Φ: one labeled edge from t to t + q for each remaining projected offset q. Flipping t and its antipode changes the count by

ΔΦ = 4(k − c(t)).

The selected pair touches 4k labeled edges, of which 2c(t) are cut. Flipping the pair exchanges cut and uncut edges: the gain is (4k − 2c(t)) − 2c(t).

If c(t) < k, the cut grows by at least 4. Eventually no improving flip remains, so c(t) ≥ k at every position. A local optimum suffices.

03 / Restore the extreme pair

The extreme pair supplies the strict majority

At the completed coloring, at least r − 1 remaining samples oppose the center. Both extreme samples also oppose it, because they reach its antipode.

(r − 1) + 2 = r + 1
opposing votes out of 2r + 1 samples

This is a strict majority, even with the center voting for itself. It forces the median to change sign. Reversing every sign reverses the median too, so the next update brings us back.

Proof of Theorem 1 · cyclic_two_cycle ↗

Each tile is one sample, including the center. The two outlined extreme tiles reach the same cycle position but count as two samples. Never merge their votes.

04 / Return to the lattice

Pull the cyclic word back to the lattice

Set x(v) = y(ℓ(v) mod 2p). Every original mask sample has exactly the value of its projected sample. The same majority argument now holds at every lattice point.

Adding N to any coordinate changes ℓ(v) by a multiple of N, so N is a common spatial period. The geometric sum bounds p; the finite cut budget bounds the number of flips.

Theorem 1 · periodic_median_two_cycle_bounded ↗

Spatial period

N = 2p ≤ (2M + 1)ᵈ − 1

Any sequence of improving flips

flips ≤ ⌊p(r − 1) / 2⌋

There are 2p(r − 1) labeled edges, and each improvement cuts at least 4 more. Therefore the process must stop.

Application

A regression test
for stopping rules.

“Repeat until the image stops changing” can run forever with a synchronous median filter and circular boundaries. This construction supplies an oscillating test input for every mask in the stated class.

next = median(current)
if next == current:       # a fixed point
    stop
if next == previous:      # a two-cycle
    report_cycle
previous, current = current, next

Initialize previous as absent and skip the second comparison on the first update. Detecting a cycle does not select the best denoised image. This is a worst-case termination result, not a claim about typical photographs.

Assumptions and scope

  • Centered, unweighted, symmetric masks; synchronous binary updates.
  • A suitable periodic image exists. Not every prescribed image size supports it.
  • Wrapped samples retain multiplicity. For distinct finite-image neighbors, use a torus side that is a multiple of N and greater than 2M.
  • Asymmetric or weighted masks and fixed, reflected, or replicated boundaries remain outside this theorem.
  • The identity mask {0} is excluded. The construction is finite, without a polynomial-time claim in the input bit length.

Context and references

Open Problems in (Digital) Geometry, Dagstuhl 2004, Problem 3, collected by Reinhard Klette, asks for a characterization of median operators admitting cycles. Our result treats its centered symmetric periodic case. The original question does not specify boundary conventions.

Goles, Montealegre, Rios-Wilson & Sene, Dynamical stability of threshold networks over undirected signed graphs provides background on total cycles and the classical period-two phenomenon for symmetric threshold dynamics.

The antipodal-cut argument comes from the supplied research archive of 21 August 2026. The October revision adds the elementary encoding, quantitative bounds, and Lean formalization.
